Bridge recovery — SlowArrival

When a bridged arrival cannot be deposited, the ETH is credited to rescue[origin] rather than reverted, because a revert on an OP withdrawal destroys the message permanently. This is the only interface that claims it — the on-chain page does not cover this path.

Reverse works during the timelock; clawback 30 days past expiry. Both send to the address above.

Relayer console — SlowRelay

Amounts in wei. address(0) means native ETH.
